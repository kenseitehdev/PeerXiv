# PeerXiv 0.9.2 — reserved DOI status clarity

## Fixed

- Reserved DOIs are displayed as inactive identifiers instead of linking to
  DOI.org before registration.
- The DOI workflow links a reserved identifier only to its Zenodo draft.
- The interface now explains that DOI resolution begins after Zenodo
  publication.

This release includes the Zenodo upload compatibility fix from 0.9.1. No
database migration is required after 0.9.0.
